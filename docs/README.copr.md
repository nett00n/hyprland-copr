## News

### 2026-11-25

Fedora 45 is out and Fedora 46 is the new rawhide: packages are now built for Fedora 43, 44, 45 and 46 (rawhide).

Updated Packages:

- OpenLogi - unpinned from 0.8.15 and moved to 0.9.0; Fedora 45 now ships rustc 1.100, which the newer releases need

### 2026-11-24

Added Packages:

- bluemancz-hyprmod - Native GTK4/libadwaita settings app for Hyprland: live preview, Bezier curve editor, monitor layout, keybinds, window rules
- bluemancz-hyprland-config, bluemancz-hyprland-monitors, bluemancz-hyprland-schema, bluemancz-hyprland-socket, bluemancz-hyprland-state - Python libraries hyprmod depends on, prefixed with their GitHub owner since they are not first-party Hyprland projects

### 2026-11-17

Added Packages:

- waycorner - Hot corners for Wayland: run a command when the pointer hits a screen corner or edge

Fixed Packages:

- waylock - pinned to 1.6.0: 1.7.0 needs a newer Zig than Fedora ships and failed on every Fedora version
- Hyprland - `Hyprland --version` now also shows the build date, branch (the release tag), commit message and commit count instead of `unknown`/`0`

### 2026-11-07

Fixed Packages:

- Waybar - 0.16.0 builds again: it now needs libcava 1.0 or newer, and the old `libcava-v0` build dependency (which installs the same files as `libcava`) was making the build environment impossible to install on every Fedora version

### 2026-11-06

Added Packages:

- bare - Lightweight vertical bar for Wayland compositors with built-in blocks (tracks tagged releases; upstream's development branch pulls a git-only PipeWire dependency that can't be built offline)

Fixed Packages:

- Hyprland - now reports its real commit and tag (`Hyprland --version` used to say `unknown`), which `hyprpm` needs to fetch matching headers and build plugins
